We filter by making a condition. is of the format: Condition format→ `Expression` `operator` `Expression`

There are many ways to compare two things.

```sql
-- compare two columns
column_1 = column_2[first_name = last_name]

-- compare column and value
column1 = value[first_name = 'John']

-- compare Function and vlaue
Function = value[UPPER(first_name) = 'JOHN']

-- compare Expression and value
Expression = value[Price * Qty = 1000]

-- compare subquery to value (ADVANCED)
subquery = value
[SELECT AVG(sales) FROM orders] = 1000
```

And in any of the condition, operators are important. The different types of operators are:

- Comparison Operators
    
    Different comparison operators:
    
    1. `=`  checks if two values are equal
    2. `!=` checks if two values are not equal (`<>`)
    3. `>` checks if value 1 greater than value 2.
    4. `>=` check if a value is greater than or equal to another value.
    5. `<` checks if value 1 is less than value 2.
    6. `<=` checks if value 1 is less than or equal to value 2.
- Logical Operators
    - `AND` - All conditions must be true in the expression to be selected in the result.
    - `OR` - At least one of the condition must be true to be selected in the result.
    - `NOT` - Reverses the condition i.e. it excludes the matching values  from the result.
- Range Operators
    - `BETWEEN` - Checks if a value falls within a specific range.
    - In this the upper bound and lower bound are inclusive. (100 - 200) considers for 100 and 200 to be in range!.
    - BETWEEN can also be represented by two comparison conditions conditions with a Logical AND
    
    ```sql
    SELECT * 
    FROM customers
    WHERE score >= 100 AND score <= 500
    
    -- is equivalent to 
    SELECT * 
    FROM customers
    WHERE score BETWEEN 100 AND 500
    ```
    
- Membership Operators
    - `IN`  - Checks if a value exists in a list.
    - `NOT IN` - Checks if a value not exists in a list.
    
    ```sql
    -- IN
    SELECT *
    FROM customers
    WHERE country IN ('Germany', 'USA')
    
    -- NOT IN
    SELECT *
    FROM customers
    WHERE country NOT IN ('UK', 'USA')
    ```
    
- Search Operator
    - `LIKE`  - if you want to search for a pattern in text.
    
    What is a pattern?
    
    In SQL to build a pattern, we need two special characters.
    
    1. `%`  - Accepts anything. (0, 1 or many matches)
        - M% - Match the ‘M’ and rest can be anything
        - %in - Match the ‘in’ and rest can be anything
        - %r%- if there is a r it will be matched.
    2. `_` - Accepts exactly one matching pattern
        - _ _ b% - There should be exactly two chars before b and rest can be anything (even nothing → rob accepted)
